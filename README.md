## ✨ المميزات

<p dir="rtl">

### 🎯 المميزات الرئيسية
- **تحويل فوري للصور** إلى فن ASCII
- **واجهة عربية متكاملة** مع دعم كامل للغة العربية
- **تصميم متجاوب** يعمل على جميع الأجهزة (كمبيوتر، تابلت، موبايل)
- **سحب وإفلات** الصور مباشرة

### 🎨 نتائج التحويل
- **نتيجتين منفصلتين**:
  - نتيجة أبيض وأسود (Monochrome)
  - نتيجة ملونة (Colorful) تحافظ على ألوان الصورة الأصلية

### 📋 خيارات النسخ والحفظ
- **نسخ النص** بنقرة واحدة
- **حفظ النتيجة كملف TXT**
- **تنسيق النتائج** للغات برمجية متعددة:
  - Python 🐍
  - JavaScript 📜
  - HTML 🌐
  - Java ☕
  - نص عادي 📝

### ⚙️ إعدادات متقدمة
- **تعديل العرض** (20 - 200 حرف)
- **اختيار مجموعة الرموز**:
  - بسيطة (@#%*+=:-.)
  - مفصلة (@%#*+=-:. )
  - كتل (█▓▒░ )
  - مخصصة
- **عكس الألوان** (Invert)
- **وضع الألوان** (أبيض وأسود / ملون)

### 🚀 أداء عالي

- **دعم صور حتى 5MB**
- **معاينة فورية** للصورة المرفوعة
- **تحويل تلقائي** بعد رفع الصورة

### 📱 تجربة مستخدم ممتازة

- **تبويبات منظمة** للنتائج

## 📖 الاستخدام

### خطوات بسيطة لتحويل الصور:

1. **رفع الصورة**:
   - اسحب وأفلت الصورة في المنطقة المخصصة
   - أو انقر لاختيار صورة من جهازك

2. **تعديل الإعدادات** (اختياري):
   - غيّر العرض حسب رغبتك
   - اختر مجموعة الرموز المناسبة
   - فعّل أو عطّل عكس الألوان
   - اختر وضع الألوان

3. **تحويل الصورة**:
   - انقر على زر "تحويل الصورة"
   - انتظر لحظات حتى تظهر النتيجة

4. **استخدم النتائج**:
   - **للنتيجة الأولى (أبيض وأسود)**:
     - انسخ النص مباشرة
     - أو احفظه كملف TXT
   
   - **للنتيجة الثانية (ملونة)**:
     - اختر اللغة البرمجية المطلوبة
     - انسخ النص المنسق
     - استخدمه في مشروعك

## 🛠️ التخصيص

### تعديل الألوان
يمكنك تغيير الألوان الأساسية في قسم `:root`:

```css
:root {
    --primary-color: #4a6fa5;    /* اللون الأساسي */
    --secondary-color: #166088;  /* اللون الثانوي */
    --accent-color: #ff6b6b;     /* لون التمييز */
    --dark-color: #333;           /* اللون الغامق */
    --light-color: #f8f9fa;       /* اللون الفاتح */
    --success-color: #28a745;     /* لون النجاح */
}
```

### إضافة لغات برمجية جديدة
أضف لغات جديدة في دالة `formatAsciiForLanguage`:

```javascript
case 'csharp':
    return `// C# ASCII Art\nstring asciiArt = @"\n${rawText}\n";`;
case 'php':
    return `<?php\n// PHP ASCII Art\n$asciiArt = <<<EOT\n${rawText}\nEOT;\n?>`;
```

### إضافة مجموعات رموز جديدة
أضف مجموعات جديدة في دالة `getCharset`:

```javascript
const charsets = {
    // ... المجموعات الموجودة
    'emoji': '😊😐😢😠😮',  // مجموعة رموز تعبيرية
    'numbers': '9876543210'  // مجموعة أرقام
};
```
